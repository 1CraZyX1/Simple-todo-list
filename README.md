# To-Do List

Простой веб-сайт «Список задач» на HTML, CSS и vanilla JavaScript.

## Возможности

- Добавление новых задач.
- Отметка выполненных задач.
- Удаление задач.
- Сохранение задач после обновления страницы.
- Очистка выполненных задач.
- Счётчик активных задач.
- Адаптивный дизайн.
- Работа без сервера и внешних зависимостей.

## Технологии

- HTML5
- CSS3
- JavaScript ES6+
- localStorage

## Локальный запуск

### Вариант 1: просто открыть файл

Откройте `index.html` в браузере.

### Вариант 2: через локальный сервер
